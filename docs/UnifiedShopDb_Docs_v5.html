vw_ProductStats

Replaces stored RatingAverage and ReviewCount on Products — a 1NF violation (stored computation). Returns ProductId, ReviewCount, RatingAverage, VerifiedReviewCount computed live from Reviews.

vw_CustomerStats

Replaces TotalOrders, TotalSpent, LastOrderDate, OrderCount on Customers — all 1NF violations. Returns CustomerId, OrderCount, TotalSpent, LastOrderDate, CompletedOrders, TotalRefunded.

vw_StockAvailability

Real-time available stock per product/variant/warehouse. Computes AvailableQty = QuantityOnHand - ReservedQuantity and NeedsReorder against configured thresholds across StockItems, ProductVariants, Warehouses.

vw_CustomerLoyaltyBalance

Current loyalty point balance derived from LoyaltyTransactions ledger. Returns CurrentBalance, TotalEarned, TotalRedeemed, NextExpiryDate. Balance is never stored — always computed.

📐 Normalisation Summary
1NF fixes — no stored aggregations, no CSV columns, no repeating groups
• Products.RatingAverage, ReviewCount → removed → vw_ProductStats
• Customers.TotalOrders / TotalSpent / LastOrderDate → removed → vw_CustomerStats
• Coupons.ApplicableCategories CSV NVARCHAR → DiscountApplicability junction table
• LoyaltyPoints INT on Customers → LoyaltyTransactions full ledger

2NF fixes — every non-key column depends on the whole primary key
• Pure junction tables (ProductTags, BrandCategories, ReviewHelpfulness, BlogPostTags, UserRoles) carry zero non-key payload
• RolePermissions: composite PK (RoleId + PermissionId); IsGranted depends on both parts

3NF fixes — no transitive dependencies
• Orders.PaymentMethod / Status / Date / TransactionId → moved to Payments
• Orders.InternalNote + AdminNote merged → single AdminNote
• Expenses.ExpenseCategory string → removed; only ExpenseCategoryId FK remains
• AuditLogs: no UpdatedAt / UpdatedBy / IsDeleted (immutable append-only; adding those would imply mutability)
